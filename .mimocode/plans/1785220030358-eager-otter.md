## Задача 1: Поднятие товаров в поиске за клики (как Авито)

**Суть:** "Приоритет в каталоге" в тарифах работает только для компаний/поставщиков/производителей. Для товаров — нет. Новый механизм: пользователь платит за каждый клик-поднятие товара. Бегунок (слайдер) costPerClick — чем больше ставка, тем выше в каталоге.

**Что делать:**
- Новая модель `ProductBoost` в Prisma: productId, userId, costPerClick (1–50₽), budget (лимит), spent (потрачено), clicks, active
- API `POST /api/products/[id]/boost` — создать/изменить буст
- API `GET /api/products/boost/status` — текущие бусты пользователя
- В `/api/products`: бустированные товары ПЕРВЫМИ, внутри — по costPerClick (больше ставка = выше)
- На `/dashboard/products` — кнопка "Поднять" со слайдером costPerClick и бюджетом
- Списание: при просмотре товара в каталоге → списание costPerClick из budget. Budget = 0 → товар опускается
- В тарифах: убрать "Приоритет в каталогах" из Pro/Premium (теперь отдельная услуга)

**Файлы:**
- `prisma/schema.prisma` — модель ProductBoost
- `src/app/api/products/[id]/boost/route.ts` — новый API
- `src/app/api/products/route.ts` — сортировка с бустом
- `src/app/dashboard/products/page.tsx` — UI буста
- `src/app/dashboard/tariffs/page.tsx` — обновить тексты

## Задача 6: Интеграция с AmoCRM

**Суть:** При первом сообщении от клиента (CLIENT) — автоматически создавать контакт + сделку в AmoCRM. Все последующие сообщения из диалога переносить в сделку.

**Что делать:**

### 6.1 Хранение настроек
- Модель `Integration` в Prisma: id, type ('amocrm'), config (JSON), enabled, updatedAt
- Или просто через env + админку — рекомендуется админка

### 6.2 AmoCRM клиент
- `src/lib/amoCRM.ts`:
  - OAuth2 авторизация (refresh_token flow)
  - `findOrCreateContact(phone, name)` — поиск по телефону, если нет → создание
  - `createDeal(contactId, name, pipelineId, statusId)` — создание сделки
  - `addNoteToLead(leadId, message)` — добавление примечания (сообщения) к сделке

### 6.3 Триггер
- В `src/app/api/conversations/[id]/messages/route.ts`:
  - При создании сообщения от пользователя с ролью CLIENT
  - Проверить: первый ли это диалог? (нет существующей сделки для этого клиента)
  - Если первый → findOrCreateContact по телефону клиента → createDeal → addNote с текстом сообщения
  - Если сделка уже есть → addNote с текстом нового сообщения
  - Телефон берётся из профиля клиента (`user.phone`)

### 6.4 Админка
- `/admin/integrations` — страница настроек:
  - Включение/отключение AmoCRM
  - Ввод: domain (xxx.amocrm.ru), client_id, client_secret, redirect_uri
  - Кнопка "Подключить" → OAuth2 flow
  - Выбор воронки (pipeline) и статуса для новых сделок
  - Тестовая отправка

### 6.5 Данные в сделке
- Имя клиента
- Номер телефона
- Ссылка на профиль в МебПортале (`mebportal.online/profile/{userId}`)
- Текст первого сообщения
- Все последующие сообщения → примечания к сделке

**Файлы:**
- `src/lib/amoCRM.ts` — новый клиент
- `prisma/schema.prisma` — модель Integration (или через env)
- `src/app/api/conversations/[id]/messages/route.ts` — триггер
- `src/app/admin/integrations/page.tsx` — настройки
- `src/app/api/admin/integrations/route.ts` — API настроек
- `.env.example` — новые переменные (если env-вариант)
